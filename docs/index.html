PrismarineJS · Minecraft in Node.js

Minecraft blocks,
as real JavaScript objects.

Represent any Minecraft block with all of its associated data — dig times, harvest rules, block states, biomes, and block entities — across dozens of game versions.

📦 npm install prismarine-block See it in action →
example.js 
const registry = require('prismarine-registry')('1.20')
const Block = require('prismarine-block')(registry)

const stone = new Block(registry.blocksByName.stone, registry.biomesByName.plains, 0)

// Can you harvest stone with an iron pickaxe?
stone.canHarvest(257)   // → true

// How long does it take to dig? (ms)
stone.digTime(257)      // → 1150

Everything a block knows about itself

One small library that turns raw Minecraft data into a rich, queryable block object.

⛏️

Dig & harvest logic

Compute precise dig times and check which tools can actually harvest a block.

🧱

Block states

Read and build block states with stateId, fromProperties and getProperties.

🌍

Biome aware

Blocks carry their biome context for accurate, world-faithful behaviour.

📐

Collision shapes

Access bounding boxes and block shapes for physics and ray-casting.

📝

Block entities

Full support for signs and other block entities, including multi-sided signs.

🔁

Java & Bedrock

Works across many versions of both editions, including Bedrock block hashes.

Get started in seconds

No build step, no config. Just install and require.

terminal 
# Install
$ npm install prismarine-block prismarine-registry

# Then in your project…
const registry = require('prismarine-registry')('1.20')
const Block = require('prismarine-block')(registry)

const diamond = Block.fromStateId(registry.blocksByName.diamond_ore.minStateId, 0)
console.log(diamond.canHarvest(278)) // diamond pickaxe → true
